Sobre esta demo: la lectura y extracción de datos la hace una IA real (Gemini, de Google), llamada en vivo desde este mismo archivo, sin costo — no está inventado ni pre-armado. Lo único simulado es el envío real del WhatsApp (para eso se necesita la cuenta de WhatsApp Business API ya configurada); el mensaje que ves es exactamente el texto que se enviaría. En la versión final para producción se puede usar Gemini, Claude, o cualquier otro modelo — la lógica es la misma.
